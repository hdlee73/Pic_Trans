# Snap Read

카메라로 찍은 사진에서 문자·숫자를 추출하고 한국어로 번역하는 웹 앱입니다.

## 화면 구성

카메라와 찍은 사진은 같은 자리에 크게 표시되고, 추출된 문자와 번역은 결과 영역에 표시됩니다.
화면 비율에 맞춰 배치가 바뀝니다 (Galaxy Z Fold 기준).

| 화면 | 배치 |
|---|---|
| 접은 상태 · 세로 | 촬영 전에는 카메라가 화면 전체. 촬영 후 위: 사진, 아래: 추출된 문자 + 번역 |
| 접은 상태 · 가로 | 왼쪽: 카메라/사진 (버튼은 세로줄), 오른쪽: 결과 |
| 펼친 상태 · 세로/가로 | 왼쪽: 카메라/사진, 오른쪽: 결과 |

## 메뉴와 기능

앱을 열면 아이폰 메일 앱처럼 목록형 메뉴가 나옵니다. 고르면 해당 촬영 화면이 열리고, 처음 들어갈 때 **사용 방법**이 한 번 나옵니다.
촬영 화면 위쪽의 **?** 버튼이나 메뉴의 "사용 방법"에서 언제든 다시 볼 수 있습니다.

| 메뉴 | 설명 | 촬영 가이드 |
|---|---|---|
| 사진 번역 | 찍은 사진 속 글자를 추출해 한국어로 | 모서리 표시 |
| 실시간 번역 | 촬영 버튼 없이 카메라 위에 번역만 겹쳐 표시. 위에서 언어 선택, **끄기**는 메뉴로 | 화면 아래 상태 안내 |
| 북스캔 · 문서 스캔 | 아래 설명 | 한 쪽/두 쪽 틀 + 제본선 |
| 명함 저장 | 이름·전화·이메일을 연락처로 | 명함 비율 틀 |
| 표 → CSV | 사진 속 표를 엑셀 파일로 | 격자 틀 |
| 구글 이미지 검색 | 구글 렌즈로 검색 | 정사각 틀 |
| QR·바코드 | 링크·와이파이·상품 검색 | 정사각 틀 |

### 북스캔

1. 위쪽 스위치에서 **한 쪽 / 두 쪽 펼침**을 고르고, 가이드 틀에 맞춰 촬영합니다 (두 쪽이면 노란 점선을 책 가운데에).
2. 편집 화면에서 책 모서리를 **자동으로 찾아** 줍니다. 어긋나면 점을 끌어 고칩니다 (손가락에 가려지는 부분은 돋보기로 보입니다).
3. **두 쪽으로 나누기**: 가운데 제본선을 자동으로 찾아 두 쪽으로 분리합니다 (노란 점 두 개로 조절).
4. **평평하게 펴기**: 기울어 찍힌 쪽을 반듯한 사각형으로 폅니다(원근 보정). 보정은 **선명(컬러)** · 문서(흑백) · 그레이 · 원본 중 고르며, 선명(컬러)는 책 가운데 그림자와 조명 얼룩을 옅게 합니다. 심하게 휘어진 쪽의 곡면까지 펴 주지는 않습니다.
5. **다음 쪽 촬영**으로 계속 찍고(연속 스캔), **완료**에서 쪽 순서·삭제를 확인한 뒤 **PDF 한 파일** 또는 **JPG 여러 장**으로 저장합니다.

## 사진 번역 사용 방법

1. **하얀 동그란 촬영 버튼**을 누르거나 갤러리 버튼으로 이미지를 고릅니다.
2. 찍은 사진이 카메라 자리에 표시되고, 자동으로 문자를 추출해 한국어로 번역합니다.
3. 글자가 일부분에만 있으면 사진 위에서 **글자 부분을 손가락으로 드래그**하세요. 그 부분만 확대해서 다시 인식합니다. (전체 인식 버튼으로 되돌림)
   글자가 옆으로 누워 있거나 거꾸로여도 결과가 좋지 않으면 사진을 자동으로 돌려 가며 다시 인식합니다. 그래도 안 되면 사진 돌리기 버튼으로 직접 돌려 보세요.
4. 사진 속 글자의 언어가 영어가 아니면 "추출된 문자" 옆에서 언어를 고릅니다. 고른 언어는 기억됩니다.
   일본어·중국어 **세로쓰기**(글자가 위에서 아래로 쓰인 글)는 언어 목록의 "(세로쓰기)" 항목을 고르세요.
5. 잘못 인식된 글자는 직접 고친 뒤 **번역**을 누르면 됩니다. 카메라 버튼으로 카메라로 돌아갑니다.

"촬영 후 자동 추출·번역"을 끄면 **문자 추출**, **번역**을 직접 눌러야 합니다.

## 안드로이드 앱

[Releases](../../releases)에서 `SnapRead-<버전>.apk`를 내려받아 휴대폰에 설치합니다.
(설정에서 "출처를 알 수 없는 앱 설치"를 허용해야 합니다. `.aab`는 Google Play 업로드용입니다.)

웹 화면(`www/`)을 [Capacitor](https://capacitorjs.com/)로 감싼 앱이며, `android/`가 안드로이드 프로젝트입니다.

### 앱 정보 · 업데이트 알림

카메라/사진 화면 오른쪽 위의 ⓘ 버튼에서 앱 이름, 버전, 만든이(이현덕, hdlee73@gmail.com)와 GitHub 릴리스 페이지 링크를 볼 수 있습니다.
앱을 열 때 GitHub 최신 릴리스를 확인하고(6시간에 한 번), 설치된 버전보다 새 버전이 있으면 알림을 보내고 앱 정보 화면에 안내합니다.
알림은 앱을 열었을 때 나옵니다 (백그라운드에서 따로 확인하지 않음). 알림을 누르면 릴리스 페이지가 열립니다.

### 아이콘

아이콘 원본은 `design/icon.svg`(선만 쓰는 단순한 모양)입니다. 안드로이드용 PNG와 시작 화면은 이 모양으로 만든 것입니다.

### 새 버전 릴리스

`v`로 시작하는 태그를 푸시하면 GitHub Actions(`.github/workflows/android-release.yml`)가 APK/AAB를 빌드해 Release를 만듭니다.

```bash
git tag v1.0.1
git push origin v1.0.1
```

또는 GitHub의 **Actions → Android Release → Run workflow**에서 버전(예: `1.0.1`)을 입력해 실행해도 됩니다.

### 서명 키 등록 (권장)

키를 등록하지 않으면 빌드마다 임시 키로 서명되어, 새 버전 설치 시 기존 앱을 지워야 할 수 있습니다.
한 번만 키를 만들어 저장소 **Settings → Secrets and variables → Actions**에 등록하세요.

```bash
keytool -genkeypair -v -keystore pictrans.keystore -alias pictrans \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 pictrans.keystore   # 출력값을 ANDROID_KEYSTORE_BASE64 로 등록
```

| Secret | 값 |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | 위 base64 출력 |
| `ANDROID_KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `ANDROID_KEY_ALIAS` | `pictrans` |
| `ANDROID_KEY_PASSWORD` | 키 비밀번호 (키스토어와 같으면 생략 가능) |

키스토어 파일은 저장소에 올리지 말고 안전하게 따로 보관하세요. 잃어버리면 Play 스토어 앱을 업데이트할 수 없습니다.

### 직접 빌드

Node 22+, JDK 21, Android SDK가 필요합니다.

```bash
npm ci
npx cap sync android
cd android && ./gradlew assembleDebug   # app/build/outputs/apk/debug/
```

## 웹으로 실행

브라우저의 카메라 권한 정책 때문에 **HTTPS** 또는 **localhost**에서 열어야 합니다.

```bash
npm ci          # OCR 파일을 www/vendor 로 복사
npm run serve
# 브라우저에서 http://localhost:8000 접속
```

## 사용 기술

- 카메라: 브라우저 `getUserMedia` API (후면 카메라 기본, 🔄로 전환)
- 문자 추출: [Tesseract.js](https://github.com/naptha/tesseract.js) — 기기 안에서 OCR 처리.
  엔진과 영어 데이터는 앱에 포함되어 있고(`npm ci` 때 `scripts/vendor.js`가 `www/vendor/`로 복사), 다른 언어는 처음 쓸 때 내려받습니다.
  앱에 포함된 엔진을 못 쓰면 CDN에서 받아 다시 시도하고, 그래도 안 되면 멈추지 않고 오류를 표시합니다.
  (안드로이드 빌드는 assets의 `.gz` 파일을 풀어서 넣기 때문에 언어 데이터는 압축하지 않은 채로 넣습니다.)
  신뢰도가 낮은 줄(아이콘·그림을 글자로 잘못 읽은 것)은 결과에서 뺍니다.
- 번역: Google 번역(언어 자동 감지), 실패하면 [MyMemory](https://mymemory.translated.net/) 무료 번역 API로 재시도 — API 키 불필요.
  앱에서는 Capacitor 네이티브 HTTP로 요청해 브라우저 CORS 제한을 받지 않습니다.
